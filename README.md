## 🚀 Featured Projects

### NexCart: Multi-Vendor E-Commerce Platform

**NestJS | TypeORM | PostgreSQL | Next.js | TypeScript**

Full-stack e-commerce platform with multi-role management and real-time operations.

- Built secure REST APIs with JWT authentication, DTO validation, and role-based access control.
- Developed admin dashboards with PostgreSQL, TypeORM, and real-time updates using Pusher WebSockets.
- Implemented authentication workflows, email verification, and order/rider management.

🔗 GitHub: https://github.com/nur-hasin/nexcart

---

### Orvexa: AI Chat Application

**Express.js | MongoDB | React.js | OpenRouter API**

AI-powered chat application focused on efficient LLM context management.

- Built token-efficient context handling with rolling summaries and message history optimization.
- Implemented rate limiting, Helmet security, and optimized AI inference workflows.
- Created a responsive chat interface with Markdown rendering and optimistic updates.

🔗 GitHub: https://github.com/nur-hasin/orvexa

---

### Stayly: Rental Property Marketplace

**Express.js | MongoDB | EJS | Passport.js**

Rental marketplace with authentication, listings, and media management.

- Built MVC architecture with RESTful routes and session-based authentication.
- Implemented authorization, validation, and database-driven workflows.
- Integrated Mapbox geocoding, Cloudinary uploads, and Joi validation.

🔗 GitHub: https://github.com/nur-hasin/stayly
